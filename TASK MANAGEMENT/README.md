TaskBuddy is a React task management app for organizing everyday work. Create tasks, update them, mark them complete, and remove them when they are no longer needed. Tasks are saved in your browser and remain available after a refresh.

## About

TaskBuddy provides a straightforward way to keep track of tasks in one place, with task data persisted locally in the browser.

## Tech Stack

- JavaScript (ES modules)
- React 19
- HTML5
- CSS3
- Vite

## Features

- Create, update, complete, and delete tasks
- Save tasks in browser storage so they persist after refresh
- Develop and build with Vite
